# Lintel brand

The Lintel mark is a bird sitting on a branch, drawn with sharp, angled shapes and a few
thin cuts of negative space (the wing, and where the belly meets the branch).

## Files

| File                               | Use it for                                   |
| ---------------------------------- | -------------------------------------------- |
| `lintel-mark.svg`                  | The mark in Lintel ink, on light backgrounds |
| `lintel-mark-black.svg`            | One-colour printing, or on light photos      |
| `lintel-mark-white.svg`            | On ink, dark backgrounds or dark photos      |
| `lintel-app-icon.svg`              | App icons and favicons: a white bird on ink  |
| `lintel-app-icon-512.png`          | The app icon where an image file is needed   |
| `favicon-16.png`, `favicon-32.png` | Browser tabs                                 |
| `apple-touch-icon.png`             | iPhone and iPad home screens (180px)         |
| `lintel-lockup.svg`                | The mark with the name, on light backgrounds |
| `lintel-lockup-dark.svg`           | The mark with the name, on dark backgrounds  |

The lockups set the name in the system font for now. Once a typeface is chosen, the name
will be converted to outlines so it looks the same everywhere.

## Colours

| Name       | Hex       | Use                                                               |
| ---------- | --------- | ----------------------------------------------------------------- |
| Lintel ink | `#1F1D1A` | The mark, text, buttons and selection. Paper on it is about 16:1. |
| Paper      | `#F6F4EF` | Backgrounds; cards are `#FFFEFB`                                  |

In dark mode ink and paper swap: paper buttons with ink text on a warm near-black
(`#11100E`). Text links are underlined, since ink text alone doesn't look clickable (see
`packages/admin/src/design/README.md`). Page titles are set in Schibsted Grotesk (OFL);
everything else uses the system font.

Lintel was violet (`#7539FD`) until November 2026.

## Using the mark

- Keep it at least 16px tall on screen (the app icon at 16px for favicons) and 8mm in print.
- Leave clear space around it of at least the height of the bird's head.
- Use only the colours above. Don't recolour, stretch, rotate, outline or add effects.
- Don't put the ink mark on busy photos or on colours that make it hard to see; use the
  white or black version instead.
