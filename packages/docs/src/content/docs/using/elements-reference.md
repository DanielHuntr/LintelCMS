The page builder's **Insert** panel has two kinds of things to add: ready-made **Sections**
and single **Elements**. This page lists every element, by the group it is in under
**Elements**. Type in the search box at the top of Insert to find one by name or by what it
does ("slider", "map", "price").

Every element starts with sensible content and a look that follows your website's colours,
fonts and corners, so it looks right the moment you add it. In the **Content** panel you see
the few things most people change first; anything else is folded away under
**More options**. How it looks (spacing, size, colours) is in the **Style** panel, per screen
size.

All elements:

- work on computers, tablets and phones;
- can be used with a keyboard and a screen reader, and keep focus visible;
- stay still for visitors who ask their device for less motion: tickers stop, sliders never
  move by themselves, numbers don't count up;
- don't load anything from another website (YouTube, maps, embeds) until the visitor asks
  for it, so no cookies are set before they choose;
- reserve their space as the page loads, so nothing jumps.

The **Forms** elements appear when the Forms plugin is on, and the **Shop** elements when the
Online shop plugin is on (Settings → Plugins).

## Tips

- **Slides, tabs and accordion items** live inside their slider, tabs or accordion. Select
  the slider and use **Add** in Layers, or duplicate a slide (⌘D or Ctrl+D).
- A **Card** with a link is one big link: put no other buttons or links inside it.
- **Icons** come from the [Lucide](https://lucide.dev) set (ISC licence), drawn into the page
  so no icon font is loaded. Leave "What it means" empty when an icon is only decoration.
- An **Embed** only shows addresses from a list of well-known sites (calendars, playlists,
  maps, design tools). Anything else can go in a [code block](/using/designing-pages/) by
  someone with permission to edit code.
- **Video**: YouTube videos play from `youtube-nocookie.com`, and Vimeo videos with tracking
  off. Choose a picture to show before it plays; otherwise a plain placeholder shows.
- **Rich text** understands a few marks: `## Heading`, `**bold**`, `*italics*`,
  the words of a link in square brackets followed by its address in round brackets, lines starting with `- ` for a list and `> ` for a quote.
