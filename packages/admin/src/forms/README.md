# Forms

The admin half of the Forms plugin (see `packages/core/src/forms`). For now it adds the
**Forms** sidebar section, after Media, with a screen saying forms are on the way. It only
shows while the plugin is on, to people with `forms:read`.

| File                    | What it does                    |
| ----------------------- | ------------------------------- |
| `forms.adminPlugin.tsx` | The sidebar item and the screen |
